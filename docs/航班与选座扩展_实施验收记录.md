# 航班、票价、选座与 DeepSeek：实施验收记录

实施日期：2026-11-20。对应《航班扩充与每日刷新_票价座位_AI接口实施方案》。本记录区分已完成的课程功能、真实模型接入以及尚未接入的真实航空服务。

|---|---|

| 航班详情 | 机场、演示航站楼、计划起降时间、跨日、飞行时长、客舱布局、行李规则、费用说明、销售截止时间 |

| 座位 | 180 座经济舱与 172 座两舱演示布局；手选、免费自动分配、付费座位、乘机人对应；正式库有 583,680 条座位记录 |
| 交易联动 | 扣客舱库存与锁具体座位为一个事务；确认、取消、过期、退订批准保持幂等；冲突组单整体回滚 |
| 退款 | 依据购票时规则和原金额计算预览；申请时保存退款额，审核后释放座位；航班取消可使用非自愿全额退款规则 |
| 管理端 | 航班页面增加班期启停、生成任务记录、手动补齐和产品规则查看；布局绑定航班禁止直接改变容量 |

所有航班、时刻、航站楼分配、票价、行李产品及客舱布局均为**课程演示配置**。品牌资料来自航司官方页面；本系统不提供真实出票、实时航空库存、真实支付或登机服务。图片是官方品牌标识，未将其描述为飞机实景照片。

`mvn verify` 通过：原有 BookingIntegrationTest 18 项；新增 FlightFeaturesIntegrationTest 19 项，共 **37 项，失败 0、错误 0**。

### DeepSeek 实际调用

使用用户配置的本地密钥请求官方模型列表成功，返回 deepseek-flash / deepseek-v4-pro。通过测试应用真实调用规划接口得到 HTTP 200、4 个数据库航班候选，`needsClarification=false`，记录见 `docs/evidence/deepseek-live-smoke.json`。

接入遵循 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)及[JSON Output 文档](https://api-docs.deepseek.com/guides/json_mode/)。实现使用固定官方主机 `/chat/completions` 和 JSON 输出；没有给模型提供 SQL、数据库地址、root 密码、用户表或乘机人信息。

实际流程是“解析条件→参数化查询当前可售数据→让模型排序公开候选→后端过滤核验”。价格和余票由后端决定；模型无法创建订单、支付、退款或增设航班。当前智能规划支持国内成人直飞单程，往返、中转、包机或新航线定制尚未启用。

## 启动与使用

本机 8080 已被其他程序占用，8081 不能监听。本次运行采用：

- 门户：http://127.0.0.1:18081
- 后台：http://127.0.0.1:18082
- 后端：http://127.0.0.1:18080

前端由 `scripts/serve-built.cjs` 提供静态页面和同源 API 代理。正常重启命令：

```powershell
# 已构建后端；在项目根目录
./scripts/run-server.ps1 -Port 18080 -Database air_ticket

# 另一终端，确保两端已经 npm run build
node scripts/serve-built.cjs
```

DeepSeek Key 保存在 `.local/application-local.yml`，该目录已被忽略，不进入源码或前端。其他环境使用 DEEPSEEK_API_KEY、AI_ENABLED、DEEPSEEK_MODEL 配置；不要复制本机真实密钥到报告和压缩包。项目默认关闭 AI，本机本地配置已启用。

每日生成依赖后端运行，停机期间不会刷新；再次启动自动补齐。后台“补齐缺失航班”可以重试失败日期，不会重置库存。旧模板的启停只影响后续生成；已有实例使用航班停售功能。当前后台提供班期启停与规则查看，完整班期编辑和规则新版本发布作为后续扩展，不允许直接覆盖已有销售快照。

## 来源与素材维护

14 家官方页面及具体下载地址、日期、图片尺寸、校验和、版权说明见 `docs/assets/airline-assets.json`。图片资源同步在 portal/admin 的 `public/images/airlines`，页面使用数据库路径和本地 placeholder，不再按中文名称模糊匹配或依赖外网占位图。

如需重新检索与下载，在项目根目录运行 `scripts/research-airline-assets.py`，再用具备 Playwright 和 Chrome 的 Node 环境运行 `scripts/inspect-airline-pages.cjs`，最后运行 `scripts/import-airline-assets.py`。两个内嵌 logo 从官方页面提取，来源与校验和同样登记。官网品牌图的版权保留，不将其标注为开放许可素材。

旧 vendor 包体积警告仍存在；本次两端构建无错误。大模型故障、预算或条件不满足时，页面明确提示并保留普通查询入口。
