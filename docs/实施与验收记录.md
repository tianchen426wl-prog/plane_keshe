# 本次业务与数据库完善验收记录

日期：2026-11-20。范围：业务代码、两个前端、MySQL 增量迁移及可运行验证。课程个人报告与 PPT 不属于本次代码实施交付。

## 已完成的业务修改

1. 统一 SecurityFilter：USER/ADMIN 凭证隔离，服务端读取当前账号状态及认证版本；所有个人操作从认证上下文取用户，客户端 userId 不再决定归属。
2. 关闭旧公开管理写路径，后台按实时菜单授权；菜单和角色限制超级管理员。统一 0=超级管理员、1=普通管理员。
3. 管理员编辑 SQL 补 WHERE；删除改停用，保护最后一个有效超级管理员。修复单舱删除 ID 维度。
4. 密码属性只允许请求写入，不序列化返回；后台用户查询改数据库分页并对手机号、身份证脱敏。
5. 抢票校验数量、起飞时间、销售状态、舱位归属；用户行锁保护未完成占位上限，requestId 唯一约束实现重放幂等。
6. 占位、取消、确认和过期由 BookingService 一致事务控制；竞争同一占位行锁；过期释放先提交，再由控制层返回 409。
7. 使用舱位库存，退出 hbxx.number 双写；容量修改按容量差调整余票，不能覆盖交易变化；1 个座位分配后总和仍为 1。
8. 占位单价快照、订单唯一 hold_id/order_no 与航班快照；重复确认不重复出单，前端历史订单优先展示快照。
9. 退订通过/拒绝/再次申请、审核意见与审核人时间；退款幂等，生命周期动作日志可在后台查看。
10. 前台分页、服务端倒计时、模拟支付标识、缓存容错、hash 登录跳转、角色页面、后台用户分页及真实零值显示。
11. 资讯详情改纯文本，关闭敏感 SQL 明细日志，CORS 明确白名单并支持配置，凭据移出可分发配置。

## 自动化测试

18 项集成测试使用 Spring Boot、MockMvc、真实 MySQL air_ticket_test，单独连接并实际提交事务，含：

- 匿名、主体类型、菜单授权、认证版本失效；跨用户归属校验。
- 负数/零/超过上限、过去航班校验；分页和日期边界。
- 重复占位及确认、占位锁价、HTTP 占位响应、聚合余票。
- 余票为 1 时 50 个并发请求恰好 1 个成功。
- 取消/确认/清理竞争；退款拒绝、再次申请、重复通过和并发通过。
- 扣库存后数据库约束故障触发完整事务回滚。
- 容量下调保护、单座位三舱初始化、历史删除保护。
- 管理员更新只影响目标行；密码字段不返回；改密使原令牌失效。
- 后台用户分页与安全响应。
