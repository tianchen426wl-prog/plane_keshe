# 前端 UI 重构实施记录

日期：2026-11-20。基于《前端UI开源调研与重构方案》，本轮修改已进入实际 Vue 前端，不是原型替换截图。

## 已落地内容

- **共用视觉规范**：新增 air-ticket-web/shared/theme.css，两端统一色彩、间距、字体、卡片、表单、按钮、状态、表格和弹层。保留现有依赖和技术栈。
- **门户导航**：品牌、主任务导航、账户菜单、手机菜单；退出统一调用已有服务端撤销流程。登录失效时同步清除 Vuex 用户，避免导航显示旧用户。
- **首页**：搜索区优先，展示实际可售航线、航空公司和资讯；移除大轮播及外网首屏图片依赖。复用本地航空公司图片。
- **搜索与结果**：复用 SearchPanel，支持城市互换和日期查询；筛选条件进入 URL，登录返回可恢复。FlightCard 替换旅客表格，价格注明基准票价并提示以可售舱位为准，避免无库存低价误导。
- **选舱**：三舱卡片、价格、实际余票、禁用状态、1～5 张数量和合计；点击锁定才调用占位接口。
- **独立确认页**：新增 /booking/:holdId，读取本人有效占位，显示锁定价格、行程、费用、服务端到期时间及模拟支付说明。支持刷新恢复、取消释放、继续购买和成功结果。
- **我的订单**：状态筛选和分页保留，列表改订单卡片，显示订单号、行程快照、舱位、数量、费用及退订操作；待支付进入独立确认页。
- **登录/注册**：桌面品牌说明与表单双栏，手机单栏；辅助页面通过共享样式保持一致。
- **后台布局**：浅色工作区、分组权限导航、面包屑式上下文、标准页头、桌面折叠和手机覆盖导航。动态菜单和服务端权限继续生效。
- **后台列表**：统一筛选栏、表格密度、分页、状态与表单；订单精简冗余列。
- **订单详情**：生命周期日志改为侧栏，顶部展示订单摘要，下方时间线解释创建、支付、状态变化及退款审核。

主要文件：portal/src/App.vue，components/SearchPanel.vue、FlightCard.vue，views/Home.vue、FlightSearch.vue、Booking.vue、MyOrders.vue；admin/src/views/layout/AdminLayout.vue、jpdd/OrderManage.vue；shared/theme.css。

## 验证结果

1. portal/admin 的 npm run build 均通过，仍有既有 vendor/资源包体性能警告。
2. 更新 scripts/browser-smoke.cjs，以稳定 data-testid 定位新购票流程。

本轮未修改 Java 业务或数据库结构，浏览器写入仅在独立测试库执行；没有把此前的 18 项后端测试冒充本轮重新执行的结果。

## 接口边界

本轮保留现有查询/交易 API。占位被处理或过期后，确认页会明确提示并引导查看订单，不会仅凭 URL 声称支付成功。支付成功结果来自本次接口实际返回，刷新后以已有订单页为准。

用户端审核原因详情、全量高级筛选/排序、价格日历、行李/中转权益和真实座位图仍按原方案的数据依赖单列扩展；没有用静态假数据补齐这些业务。库存、金额和截止时间由服务端最终校验。
